# Advanced TypeScript Workshop

Use the [learning platform](https://soverius.ai/learn/typescript-workshop) for the slides,
exercise instructions, test commands and progress.

Install Node.js 24 and pnpm, then run `pnpm install` from this checkout.
Open the exercise files under `labs/` and run the command shown in the
learning platform from the repository root.

This branch contains the reference implementations. Switch to `participants` for the starters.
